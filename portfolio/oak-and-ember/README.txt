OAK & EMBER COFFEE CO. — PORTFOLIO DEMONSTRATION
Created for Next Step Socials

HOW TO OPEN
1. Extract the ZIP.
2. Open the oak_ember_demo folder.
3. Double-click index.html in any modern browser.
4. No hosting or local server is required.

FEATURES
- Responsive layout and mobile navigation
- Interactive three-category menu
- Scroll-reveal effects (with reduced-motion support)
- About, gallery, hours/location, and contact sections
- Illustrative art built in CSS; no external photos needed
- Google Fonts are optional; fallback fonts work offline

IMPORTANT
Oak & Ember Coffee Co. is fictional. All business information, prices,
hours, address, and menu items are samples. The contact form does not
transmit or store information. Replace sample details and connect a real
backend before using the site for a real business.
