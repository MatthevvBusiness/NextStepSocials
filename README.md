# Next Step Socials

Official six-page Next Step Socials website, plus portfolio demonstration.

## Website
Open `index.html` locally. Other pages: `services.html`, `pricing.html`, `portfolio.html`, `about.html`, `contact.html`.

## Portfolio demo
Open `portfolio/oak-and-ember/index.html` locally.

Oak & Ember Coffee Co. is a fictional demonstration project. Its business details are examples, not real client information.

This repository contains static HTML, CSS, JavaScript, and SVG files. GitHub Pages is not automatically enabled by uploading them.

The main homepage and portfolio page both link to the local Oak & Ember demonstration at `portfolio/oak-and-ember/index.html`.

Sitewide subtle background motif is in `assets/sitewide-pattern.svg` and applied by `assets/styles.css` across all six agency pages. Dark CTA sections retain their contrast.
