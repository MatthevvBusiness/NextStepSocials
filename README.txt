NEXT STEP SOCIALS — LOCAL WEBSITE PREVIEW
=========================================

This is a static, six-page website for Next Step Socials. It is designed to run privately on your own computer. It is NOT published to the internet.

HOW TO OPEN IT
--------------
EASIEST METHOD (Windows):
1. Extract the ZIP file to a folder you can find, such as Desktop\NextStepSocials.
2. Open that folder.
3. Double-click index.html.
4. Your browser should open the homepage.
5. Use the navigation menu to visit Services, Pricing, Portfolio, About, and Contact.

OPTIONAL LOCAL SERVER (recommended):
If you have Python installed:
1. Open the extracted folder in File Explorer.
2. Click the address bar, type cmd, and press Enter.
3. Run: python -m http.server 8000
4. Open http://localhost:8000 in your browser.
5. To stop the server, return to the Command Prompt and press Ctrl+C.

EDITING
-------
- Text and page content are in the six .html files.
- Colors, spacing, and layout are in assets/styles.css.
- Navigation, footer, and contact form behavior are in assets/script.js.
- Change the BUSINESS_EMAIL value in assets/script.js to an email address you control before using the contact form.

IMPORTANT BEFORE PUBLISHING
---------------------------
- Replace the placeholder email with your real business email.
- Confirm the package deliverables, limits, website page counts, revision limits, and contract terms.
- The contact form is a local demo. It opens an email draft after you configure the email address; it does not store or submit leads to a server.
- The portfolio contains clearly labeled concept work, not real client projects.
- Domain registration, hosting, paid ads, premium third-party apps, e-commerce, booking systems, and other external costs are not automatically included in your service packages.

PRIVACY
-------
Opening the files locally does not publish them. Other people cannot visit your local copy over the public internet. Do not upload the folder to a hosting provider until you are ready.
